## 📦 Tech Stack Overview

- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Prisma ORM
- **Database**: PostgreSQL (Neon)
- **Authentication**: NextAuth.js with Google OAuth
- **AI**: Google Gemini 2.0 Flash
- **UI Components**: Radix UI
- **Charts**: Recharts
- **State**: React Context API

---

## 🎯 Key Features

- **Account Management**: Track multiple bank accounts, credit cards, and savings
- **Transaction Tracking**: Record income and expenses with categories and tags
- **Budget Planning**: Create and monitor budgets with alerts and sub-categories
- **Savings Goals**: Set and track progress toward financial goals
- **Recurring Transactions**: Automate recurring bills and income
- **Split Bills**: Track shared expenses and settlements
- **AI Assistant (Saathi)**: Get personalized financial insights and advice
- **Receipt Management**: Attach receipts to transactions
- **Analytics**: Visualize spending patterns and trends
- **Export/Import**: Backup and restore data in JSON/CSV formats
